# Project Pro

A minimal, glassy project manager dashboard for Pulsar.

- 6 themes (Aurora / Match Pulsar / Midnight / Daylight / Mono / Custom)
- Project templates: Empty, Node.js, Python, Web, React (+ optional git init)
- Auto-launch on startup, search, drag & drop, sorting, rich appearance settings

## Keys
- `ctrl-alt-p` toggle dashboard
- `ctrl-alt-n` new project from template
- `ctrl-alt-shift-a` add current project
- `ctrl-alt-shift-t` cycle theme
